# Raffael Advocacia — site

Página única (HTML, CSS e JavaScript em `index.html`) do escritório Raffael Advocacia (OAB/CE 44.811, Mauriti-CE).

## Estrutura

- `index.html` — página completa
- `assets/` — fotos, recortes e vídeo de fundo usados na página

## Como visualizar

Abra o `index.html` no navegador. Para testar com servidor local:

    python3 -m http.server 8000

e acesse http://localhost:8000.

## Observações

- A foto de capa e o vídeo de fundo (`balanca-da-justica.mp4`) são carregados pelo caminho `assets/`.
- As fotos de banco de imagens são do Pexels (licença gratuita). Para mantê-las, confira a licença antes de publicar.
